# Vishal V — Personal Portfolio

A personal portfolio website built to showcase my projects, technical interests, and learning journey in Computer Science, AI/ML, and AI for Biology.

The website combines a dark, magical-forest aesthetic with interactive animations, custom visual assets, and scroll-driven storytelling.

**Live Website:** [View Portfolio](YOUR_LIVE_PORTFOLIO_URL)

## ✨ Features

- **Phoenix Loader** — A custom loading experience that transitions into the main landing page.
- **Scroll-Driven Animations** — Visual transitions and animations controlled by the user's scrolling progress.
- **Tree Growth Timelapse** — A sequence of image frames that visualizes tree growth as the user scrolls.
- **Magic Tunnel** — An animated visual transition connecting the landing experience to the portfolio sections.
- **Milestone Navigation** — Navigation through Projects, Skills, About, and Contact sections.
- **Cursor Particle Effects** — Interactive sparkle and particle effects that respond to cursor movement.
- **Custom Visual Assets** — SVG graphics, animation frames, and atmospheric visual effects.

## 🏗️ Technical Highlights

### Component-Based Architecture
The interface is organized into React components to separate major visual elements and interactive experiences.

### Scroll-Driven Animation
Scroll progress controls selected animations and visual transitions, creating a continuous, interactive experience.

### Canvas-Based Particle System
A custom particle system renders atmospheric effects and cursor interactions, with particle limits configured to manage rendering workload.

### Frame-Based Animation
The tree-growth timelapse uses a sequence of image frames to create a visual progression controlled by scroll position.

### Custom UI and Visual Effects
The project combines CSS styling, SVG assets, and animation logic to create a distinctive visual identity rather than relying entirely on prebuilt interface components.
